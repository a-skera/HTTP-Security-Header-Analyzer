# HTTP Security Header Analyzer

A Python-based security utility that analyzes HTTP
response headers and identifies missing security protections.

## Features

- HTTP response inspection
- Security header detection
- Missing header identification
- Header value inspection
- HTTP status reporting
- Redirect handling

## Installation

pip install -r requirements.txt

## Usage

python analyzer.py https://example.com

## Technologies

- Python
- Requests
- argparse
